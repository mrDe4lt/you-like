# EduLearn - Professional Online Learning Platform

A modern, secure, scalable e-learning platform similar to Udemy and Coursera, built with cutting-edge technologies.

## 🚀 Features

### For Students
- User authentication with JWT
- Browse and purchase courses
- Video streaming with progress tracking
- Complete quizzes and exams
- Download certificates
- Course progress dashboard
- Discussion forum
- Course ratings and reviews

### For Instructors
- Course creation and management
- Video upload and management
- Quiz creation
- Student performance tracking
- Revenue analytics
- Student enrollment management

### For Admins
- User management
- Course moderation
- Payment management
- Analytics dashboard
- Revenue tracking
- User activity monitoring

## 📋 Tech Stack

### Frontend
- React.js with Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Axios

### Backend
- Node.js & Express.js
- MongoDB & Mongoose
- JWT Authentication
- bcryptjs

### External Services
- Cloudinary (Video Storage)
- Flutterwave (Payments)
- SendGrid (Email)
